# 🎮 Color Beat

A fun and colorful memory sequence game built with HTML, CSS, and JavaScript! 💗

##  How to Play
- Watch the sequence of glowing tiles.
- Repeat the sequence in the correct order.
- Each level adds another tile.
- You have 3 lives. How far can you go?
